## О проекте

Реализован аналитический пайплайн обработки IT-вакансий
с использованием объектного хранилища RustFS, собственной
реализации MapReduce на Python и аналитической СУБД DuckDB.

Данные читаются через S3 API из бакета `hh-lake`.

## Подготовка окружения

Для воспроизведения требуется локальный RustFS с бакетом
`hh-lake` и исходным CSV в `raw/vacancies.csv`.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Ключи RustFS задаются в локальных переменных окружения
`RUSTFS_ACCESS_KEY` и `RUSTFS_SECRET_KEY`
либо берутся из конфигурации локального контейнера Docker.

Пароли и токены в репозитории не хранятся.

## Конфигурация RustFS

Пример конфигурации объектного хранилища расположен
в `infra/compose.example.yaml`.

Конфигурация основана на учебном стенде из ДЗ № 2:
RustFS 1.0.0, четыре каталога-диска, Erasure Coding EC:2.

Учётные данные в конфигурации не хранятся.
Для запуска необходимо задать переменные окружения:

- RUSTFS_ACCESS_KEY
- RUSTFS_SECRET_KEY

Относительные пути bind-mount вычисляются относительно
каталога с файлом Compose. Для нового развёртывания
требуются отдельные каталоги хранения.

Исходный CSV загружается в бакет hh-lake под ключом
raw/vacancies.csv.

Пример конфигурации предназначен для отдельного стенда.
Запуск рядом с существующим RustFS на тех же портах
9000 и 9001 приведёт к конфликту.
